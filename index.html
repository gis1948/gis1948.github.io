How we build

Three rules that decide what ships and what gets written down.

01

Local-first by default

Our agent runs on your machine against your own model server. Inference, files and test runs stay where the work is; the optional hosted writer is off unless you switch it on and supply the key yourself.

02

Verification over promises

A task is not done because the model said so. Writes are approved and read back byte-for-byte, tests are executed, and repairs stop after a bounded number of attempts instead of looping.

03

Honest status

If a feature is a placeholder, we call it a placeholder. If a benchmark scored zero, the number goes in the release notes. This site applies the same rule to every product on it.

03

The family mark

One geometry, recoloured per product.

The Jusoor mark is the union outline of two identical squares, one rotated forty-five degrees against the other — drawn from the same construction used across classical Islamic geometric tiling. It reads as an abstract sixteen-point star, with no crescent, dome or calligraphy.

The construction never changes between products. Only the gradient does, so nine products stay recognisably one family while each keeps its own identity.

  • JusoorAI teal → gold
  • GisCode blue → violet
  • Jusoor emerald → gold
