Free Downloads

Free software, released only when it is safe to hand over.

Everything free from Jusoor will live here: installers, packages, release notes, requirements and a SHA-256 checksum for every file. Nothing is offered until its licence, integrity and readiness are settled — so today this page is a release ledger, not a download page.

No public download is open yet

Six builds exist across the family. None of them clears all four release gates — licence, rights, integrity, readiness — so none is offered. When one does, its card gains a real download button, a checksum you can verify and release notes, and this notice changes.

Free is not the same as publishable

A free edition can still have a proprietary installer, bundled third-party components, or a licence that does not grant redistribution. Each of those is checked before a file is listed.

Nothing unsigned

An installer that Windows cannot verify is a security problem for the person running it. Unsigned builds stay off this page, even when they work.

Checksums you can check

Every published file will carry its size and SHA-256 on this page and in the release notes, so you can confirm the bytes match before you run anything.
