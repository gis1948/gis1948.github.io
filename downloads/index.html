Free Downloads

Free software, released only when it is safe to hand over.

Everything free from Jusoor lives here: packages, release notes, requirements and a SHA-256 checksum for every file. Two builds are open today — GisWind 1.0.9 for Windows and GisCode Core 0.1.0-alpha.1 — and the rest stay listed with the reason they are not, so this is a ledger you can trust rather than a sales page.

Two builds are open: GisWind 1.0.9 and GisCode Core 0.1.0-alpha.1

Both clear the gates the owner set for them. GisWind 1.0.9 is self-contained, needs no .NET installation, and ships its LICENSE, THIRD-PARTY-NOTICES and README. GisCode Core 0.1.0-alpha.1 is Apache-2.0, with LICENSE, NOTICE and TRADEMARK shipped beside the binary. Both publish their size and SHA-256 below and in their release notes. Neither is code-signed, so Windows SmartScreen asks for confirmation on first run — the cards say so rather than hiding it, and the checksum is how you verify the bytes instead. Every other build stays listed below with the reason it is not offered.

Free is not the same as publishable

A free edition can still have a proprietary installer, bundled third-party components, or a licence that does not grant redistribution. Each of those is checked before a file is listed.

Unsigned, and said out loud

Neither published build has a code-signing certificate, so Windows shows a SmartScreen warning the first time it runs. Rather than pretend otherwise, each card states that and publishes its SHA-256, so you can check the bytes you received against the hash in the release notes. A signed build is still the goal.

Checksums you can check

Every published file will carry its size and SHA-256 on this page and in the release notes, so you can confirm the bytes match before you run anything.
