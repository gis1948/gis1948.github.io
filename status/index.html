Engineering status · 21 November 2026

What has been proven, and what has not.

GisCode is in development. This page records the evidence for that sentence: what the automated suite shows, what packaged-GUI qualification has passed, and which steps are still open. It distinguishes a test run from a qualified application, because they are not the same claim.

Core: early alpha Pro: not qualified for distribution
01

Automated test suite

The whole-repository suite, run on 21 November 2026.

2,921tests passed
18skipped
0failures in that run
  • What it covers: the agent's planning and repair loop, the deterministic file operations, approval and cancellation paths, workspace confinement and path rejection, model selection and provider handling, edition boundaries, and the interface's own identity and layout checks.
  • What it does not cover: how the packaged executable behaves on a real desktop. A pytest run exercises code, not the built application a person downloads.
  • Skipped tests are not passes. The 18 skips are environmental — a test that needs a resource this run did not have is counted as skipped, and stays visible here rather than being folded into the total.
02

Packaged-GUI qualification

Driving the built application, which is a different and slower check.

  • Latest candidate: two GUI scenarios passed, each run independently rather than consecutively in one session.
  • Still blocked: three GUI scenarios could not be completed, because the resources they need were not available. They are recorded as blocked, not as passed.
  • Installer: the standalone installer is not built or qualified. What exists is a single unsigned executable for Core's alpha.
  • Second PC: qualification on a second machine has not been carried out, so the current evidence describes one machine.
  • GisCode Pro: not qualified for distribution. The Pro tree builds, but the release gate has not been cleared.

03

What this page is not

The claims that are deliberately absent.

Not production-ready

An alpha that passes its suite is still an alpha. Reliability on larger, multi-file tasks is not measured, and small tasks are where the evidence is.

Not fully qualified

The automated suite and packaged-GUI qualification are different gates. The first is green; the second has open scenarios.

No benchmark claims

No comparison against other tools, no performance numbers and no model-quality ceiling are published here, because none has been independently measured.

No internal detail

This page deliberately carries no file paths, machine names, process identifiers or logs. It records outcomes, not the infrastructure that produced them.

How this page changes

Only from a dated run whose result has been verified independently of the change being announced. A figure is never carried forward because it was true last month, and a blocked scenario is only upgraded when it has actually run. If a claim cannot be reproduced, it comes off the page.
