Jusoor Admin Console

A desktop console for operating the Jusoor app's data. Built for the people who run the service, not for end users — so the download sits behind an access password.

Completed · 1.1.8 · Windows

What it does

It talks to the same Firestore database the mobile apps use, through a service account, so an operator can inspect and correct data without writing scripts or opening a console in a browser.

  • Discovers every collection automatically, with live document counts — no hardcoded list to maintain.
  • Browses and edits documents as cards: strings, numbers, booleans, nulls, timestamps, geo points, references, bytes, arrays and nested maps all round-trip faithfully.
  • Edits safely: add, change or remove fields with a visible diff and a server-conflict warning before saving; custom or generated document IDs; batch delete; search and sort per field.
  • Moves data in and out: export a collection to JSON, import it back with skip-existing, merge or overwrite, preserving Firestore-specific values.
  • Runs locally as an Electron app on Windows, with the admin PC trusting its own build.

Why it is not a public download

The console connects with a service account that has full admin rights and bypasses the app's own security rules. Handing that binary to the wrong person is a data incident, not a support problem. The installer therefore lives in private storage and is served only after a password check performed on the server — the file is never a public link, and the password can be changed at any time without re-uploading anything.

If you need access, ask the owner for the current password. Do not share it in chat groups or email threads, and never commit the service-account key file to a repository.

Open the password gate

Download requires the access password. Without it the page shows only a sign-in form.

Status

Version 1.1.8, built 15 November 2026: feature work complete and tested on the admin PC. Not code-signed, so Windows asks for confirmation on first run. There is no public release channel and no auto-update.
