GisCode Core

A local-first AI coding agent for Windows.

Plans, writes and verifies code on your own machine against your own local model server.

Ask about GisCode Core

Screenshots pending. Core screenshots, a 60-second demo of a verified task, and an annotated diagram of the plan/edit/verify loop.

What it does

  • Takes a request through plan, edit, verify and bounded repair, then reports whether the task actually completed.
  • Runs against a local llama-server you supply. No Ollama dependency, no bundled weights, no cloud inference by default.
  • Added an optional hosted writer that is off by default and reads its key only from the environment at call time.

Five deterministic operations

  • create_file, read_file, list_files, search_text and replace_text work with no model at all.
  • Each one reports exactly which operation it performed; anything outside that set is refused with a specific reason instead of being approximated.

Safety by construction

  • Writes require approval, a pre-edit snapshot is kept outside the project, and a byte-level read-back confirms the edit landed.
  • Workspace confinement rejects paths that escape the project, including .., symlinks and UNC forms.
  • Commands run with cwd locked to the workspace, with timeouts and 1 MB output caps.

What is not there yet

  • No installer, no packaged build and no release binary yet: v0.1.0 is a source snapshot.
  • Reliability on larger tasks is not measured. Small, well-scoped tasks complete end to end; multi-file or long-running jobs often need steering.
  • Model quality is the main constraint. An October 2026 benchmark using the small local models in use scored 0 of 8.
  • Windows 10/11 is the tested platform. POSIX paths exist in the code but other platforms are untested.
