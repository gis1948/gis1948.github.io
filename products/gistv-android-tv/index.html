GisTV for Android TV

Lean-back IPTV for the television.

The big-screen client: live TV, categories, series and VOD with a remote-first interface and local favourites.

Ask about GisTV for Android TV

Inside the product

One of four clients in the GisTV family.

What it does

  • Browses live TV, categories, series and video on demand from Xtream-style IPTV sources.
  • Favourite groups with an anchored navigation model: Next/Previous always cycles inside the list you started from, never across the whole catalogue.
  • Fullscreen player that hides the system bars and restores them on exit.
  • Playlist management and multi-profile support on the device.

Deliberate design choices

  • The TV client shares no sync code path at all. Favourites stay local because a television is a single-user, lean-back device.
  • Verification for this client is a signed build plus an on-device crash-buffer smoke test; there is no instrumented test suite in the tree.

What is not there yet

  • Store assets were prepared for version 1.0.5; nothing here confirms the current publishing state of that listing.
  • The project tree arrived as a transfer and carries no LICENSE or EULA, so redistribution rights are unverified.
  • It is not available to download from this site.
