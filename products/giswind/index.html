GisWind

The Windows desktop client.

A Windows application for the same IPTV sources, with a LAN media server, paired devices and a portable build.

Ask about GisWind

Screenshots pending. Windows desktop screenshots, and a capture of the LAN pairing flow.

One of four clients in the GisTV family.

What it does

  • Desktop IPTV playback with the same anchored channel navigation as the mobile clients, including scroll-wheel and keyboard zapping.
  • Runs a local media server for paired devices on the same network, with a generated password when none is set.
  • Opens the smart link in the system browser rather than an embedded view.

Security posture, as documented by the project

  • LAN authentication is always required; the old empty-password default is gone.
  • Loopback, link-local and private address ranges are rejected where the protocol expects a public target, and credentials are redacted from logs.
  • Provider credentials still live in the local database at rest, and cleartext HTTP remains permitted because typical IPTV sources require it.

What is not there yet

  • The portable package is about 200 MB and unsigned; there is no MSI or signed installer.
  • The project tree carries no LICENSE or EULA, so redistribution rights are unverified and no download is offered.
  • No desktop screenshots have been captured for publication.
