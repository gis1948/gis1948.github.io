GisCode Pro

The professional edition, built for the full engineering loop.

A separate professional edition that extends the agent with terminal, device, media and release surfaces.

Ask about GisCode Pro

Inside the product

Part of the GisCode product line: positioning, the Core/Pro comparison, the roadmap and the upgrade path sit on one page. Qualification evidence is on engineering status.

What it adds

  • Terminal and tooling surfaces alongside the core chat and project workflow.
  • An iOS build path driven through xtool, plus a device preview surface for checking output on real hardware.
  • GisLogo, Developer & Release tooling, and Generate Video as first-class Pro workspaces.
  • Separate status and history tabs, and settings for the optional hosted writer.

Core and Pro are different products

  • Pro is built from its own private tree. It is not a module that Core unlocks, and Core does not require Pro.
  • Setting GISCODE_EDITION=pro unlocks nothing in Core: the Pro code is simply absent from the public snapshot.
  • The edition boundary is enforced in the export pipeline, and a test fails if a Pro module appears that the boundary manifest does not name.

What is not there yet

  • Pro is in development and is not distributed publicly.
  • The iOS build path is experimental and depends on external tools (xtool and Xcode) on macOS.
  • The Project Doctor tab is presently a placeholder that states no Project Doctor service is connected in this build.
  • A live device run is not yet part of acceptance for the release.
