## GisCode

**GisCode — your local AI engineering workstation.** A complete engineering
environment that combines local model execution, intelligent orchestration,
coding agents, verification, and eventually distributed computing.

It runs on the machine in front of you. Models are GGUF files loaded through
llama.cpp, or a local Ollama / LM Studio / OpenAI-compatible endpoint; nothing
leaves the machine unless a person configures a remote provider. Work is planned
before it is written, a diff is approved before it is applied, and an edit is
verified by reading the bytes back rather than by trusting the report.

### Core and Pro

| | GisCode Core | GisCode Pro |
|---|---|---|
| Edition | Free, standalone | Developer edition, built from a private tree |
| Shared | Local model execution, quantization, local providers, plan and approval, verification, workspace confinement | the same |
| Adds | — | Terminal, device preview, release tooling, iOS build path, history and status tabs, ad-free |
| Status | Early alpha, published (unsigned) | Private pre-release, not qualified for distribution |

Core is not a trial: it has no activation or entitlement mechanism, and setting
the edition in Core unlocks nothing because the Pro code is absent from that
tree. Pro is a separate install that adds the rest of the engineering workflow.
There is no price and no purchase path published, because Pro is not qualified
for distribution yet.

Cluster and multi-machine work distribution, team management, advanced
distributed inference and further Pro Advanced features are **future candidates**
— not approved for implementation and not on a schedule.

## Local-first engineering

Everything Jusoor publishes follows the same assumptions: compute is local and
personal, a model is a component rather than an oracle, and a refusal with a
clear reason is more useful than a guess. That is why product pages carry the
stage a product has actually reached, downloads carry a SHA-256 and the reason a
build is or is not offered, and the status page separates a passing test suite
from a qualified application.

## Contributing

The pages in this repository are **published output**, not the source of truth.
They are generated by the owner's build and a future publish will overwrite
hand edits made here, so please do not send page rewrites as pull requests.

Useful contributions:

- **Corrections.** A statement on the site that is wrong, out of date, or not
  backed by evidence — open an issue with the page and what the record actually
  says. Factual corrections are the most valuable thing this repository can
  receive.
- **Site defects.** Broken links, unreadable contrast, a layout that breaks at a
  specific width, or a page that fails without JavaScript. Open an issue with the
  route, the browser and a screenshot.
- **Accessibility.** Anything that makes the site harder to use with a keyboard,
  a screen reader or reduced motion.

Please do not open issues asking for release dates, price lists, or downloads
that are not on the site: none of those are decided in this repository, and the
site is deliberately silent where the engineering has not caught up.
